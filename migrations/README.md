# Migrations（端末間の移行作業ガイド）

dotfiles の変更のうち、**`git pull` だけでは他の端末に反映されない作業**
（パッケージの入れ替え、ツールのインストール方法の変更、不要ファイルの削除など）を
1件1ファイルで記録するディレクトリ。

別の端末では Claude Code で `/dotfiles-migrate` を実行すれば、未適用の移行を判定して順に実行する。

## ファイル命名

```
migrations/YYYY-MM-DD-<kebab-case-summary>.md
```

- 日付はその移行を最初に行った日。ファイル名順 = 適用順
- `_` で始まるファイル（`_template.md`）と `README.md` は移行ではない

## 適用済みかどうかの判定

状態ファイルは持たない。各移行の **「完了チェック」** に書いたコマンドを実行し、
すべて期待どおりなら適用済みとみなす。そのため手順は冪等に書き、完了チェックは
「その端末の現在の状態」だけで判定できるものにする。

## 新しい移行を追加するとき

1. `_template.md` をコピーして `YYYY-MM-DD-<summary>.md` を作る
2. 最初の端末で実際に行った作業をもとに、**他の端末で必要な手順**を書く
   （リポジトリ側の変更はコミット済みで `git pull` で入る前提）
3. 移行を伴う変更と同じ PR に含める
